# 32-bit Counter in Verilog
A 32-bit synchronous counter developed as part of my
FPGA and digital hardware design self-study.

## What I implemented
- Half-adder and full-adder
- 32-bit ripple-carry adder using generate
- 32-bit counter with enable and synchronous reset
- Simulation testbenches
- FPGA top-level wrapper for the PYNQ-Z2

## Tools
- Verilog HDL
- AMD Vivado 2026.1
- PYNQ-Z2 FPGA board
